# Scapr

## Summary

A customer leaves an unhappy review under a hardscaper's Google profile:  
"Looks nothing like what I had hoped!"  
  
Not because the hardscaper is incapable, or becuase they did a bad job.  
Because the hardscapers vision didn't align with the client's imagination.  
  
Scapr solves this problem.

## Tech Stack

Frontend: Next.js + Tailwind CSS
Backend: Supabase
Storage: Supabase Storage
AI Infra: Replicate API
Payments: Stripe
